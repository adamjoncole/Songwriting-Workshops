# Songwriting Workshops

Welcome! This page contains two standalone songwriting programs that you can download and use on your computer.

## 🎵 Original Song Workshop

Create, edit, preview and organise original songs.

**[⬇ Download Original Song Workshop](https://github.com/adamjoncole/Songwriting-Workshops/raw/refs/heads/main/Original-Song-Workshop.html)**

## 🎭 Song Parody Workshop

Write, edit, preview and organise song parodies.

**[⬇ Download Song Parody Workshop](https://github.com/adamjoncole/Songwriting-Workshops/raw/refs/heads/main/Song-Parody-Workshop.html)**

## How to use the programs

1. Click the download link for your chosen workshop.
2. Save the HTML file to your computer.
3. Double-click the file to open it in Microsoft Edge or Google Chrome.
4. Start writing!

No installation is required.

## Saving and opening songs

- **Save Song As…** — Save an individual song as a JSON file.
- **Open Song…** — Import a previously saved song.
- **Save Gallery As…** — Save a complete collection of songs.
- **Open Gallery…** — Open a previously saved collection.

**Important:** Save your existing gallery before opening another one, and keep backup copies of your song files.

## Updates

Updated versions of both workshops will be made available here. Download the latest HTML files whenever a new version is released.

If a download opens as text instead of saving, right-click the link and choose **Save link as…**. Ensure the filename ends in `.html`.

For best results, use an up-to-date version of Microsoft Edge or Google Chrome.
